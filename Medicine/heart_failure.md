# Heart Failure

## Definition
Clinical syndrome resulting from structural/functional cardiac abnormality causing impaired ventricular filling or ejection, leading to congestion and/or reduced tissue perfusion.

## Classification
| By EF | Definition |
|---|---|
| HFrEF | EF ≤40% |
| HFmrEF | EF 41–49% |
| HFpEF | EF ≥50% |

| By NYHA Functional Class | Symptoms |
|---|---|
| I | No limitation |
| II | Slight limitation, symptoms with ordinary activity |
| III | Marked limitation, symptoms with less-than-ordinary activity |
| IV | Symptoms at rest |

## Etiology
- HFrEF: ischemic heart disease (most common), dilated cardiomyopathy, valvular disease, myocarditis
- HFpEF: hypertension, diabetes, obesity, restrictive/hypertrophic cardiomyopathy, aging — diastolic dysfunction predominant

## Pathophysiology
- Reduced cardiac output → neurohormonal activation: RAAS, sympathetic nervous system, natriuretic peptides
- Compensatory but ultimately maladaptive: salt/water retention, vasoconstriction, cardiac remodeling (hypertrophy/dilation), fibrosis
- Frank-Starling mechanism initially compensates; eventually fails

## Clinical Features
- Left-sided (congestion): dyspnea, orthopnea, paroxysmal nocturnal dyspnea, bibasilar crackles, S3 gallop
- Right-sided (congestion): raised JVP, hepatomegaly, pedal edema, ascites
- Low output: fatigue, cold extremities, hypotension in severe cases
- Framingham criteria (major/minor) classically used for diagnosis

## Investigations
| Test | Utility |
|---|---|
| BNP / NT-proBNP | Elevated in HF; high negative predictive value if normal — useful to rule out HF in dyspnea workup |
| Echocardiography | EF, wall motion, valvular disease, diastolic function — key investigation |
| ECG | Underlying ischemia, arrhythmia, LVH |
| Chest X-ray | Cardiomegaly, pulmonary venous congestion ("bat wing" in pulmonary edema), Kerley B lines, pleural effusion |
| BNP cutoffs | Acute dyspnea: BNP <100 pg/mL makes HF unlikely; >400 pg/mL supports HF (intermediate range needs clinical correlation) — per current knowledge, verify against latest guideline |

## Management

### HFrEF — Guideline-Directed Medical Therapy ("Four Pillars")
| Drug class | Example | Benefit |
|---|---|---|
| ACE-I/ARB or ARNI | Enalapril / Sacubitril-valsartan | Mortality benefit; ARNI superior to ACE-I in landmark trial |
| Beta-blockers | Bisoprolol, carvedilol, metoprolol succinate | Mortality benefit (start low, titrate slowly, avoid in decompensated/acute HF) |
| MRA (Mineralocorticoid receptor antagonist) | Spironolactone, eplerenone | Mortality benefit; monitor K+ |
| SGLT2 inhibitors | Dapagliflozin, empagliflozin | Mortality/hospitalization benefit regardless of diabetes status — now a foundational pillar (guideline update) |

- Diuretics (loop — furosemide): symptomatic relief of congestion, no proven mortality benefit
- Digoxin: symptom control, reduces hospitalization, no mortality benefit; narrow therapeutic index
- Hydralazine + nitrates: added benefit shown especially in African American patients in landmark trial
- Device therapy: ICD (primary prevention if EF ≤35% despite GDMT), CRT (if EF ≤35% + LBBB + QRS ≥150 ms)

### HFpEF
- SGLT2 inhibitors now show benefit (guideline update — verify against latest recommendation)
- Treat underlying cause (HTN, diabetes), diuretics for congestion
- No strong mortality-benefit drug class historically (unlike HFrEF) — evolving area

### Acute Decompensated HF / Acute Pulmonary Edema
- Sit patient up, oxygen
- IV loop diuretics (furosemide)
- Vasodilators (nitrates) if not hypotensive
- Inotropes (dobutamine) if hypotensive/cardiogenic shock
- Treat precipitating cause (ACS, arrhythmia, infection, non-compliance)
- Non-invasive ventilation (CPAP/BiPAP) for respiratory distress

## Complications
- Cardiorenal syndrome, arrhythmias (AF common), cardiac cachexia, hepatic congestion ("nutmeg liver"), sudden cardiac death

## High-Yield One-Liners
- BNP/NT-proBNP: best used to rule out HF (high sensitivity) when low; not fully specific when elevated
- Four pillars of HFrEF therapy: ACEI/ARB/ARNI, beta-blocker, MRA, SGLT2 inhibitor — all four reduce mortality
- Beta-blockers are contraindicated in acute decompensated HF but essential in chronic stable HFrEF
- Spironolactone requires potassium monitoring — risk of hyperkalemia, especially with ACEI/ARB
- S3 gallop = classic sign of systolic (volume-overloaded) heart failure; S4 suggests diastolic dysfunction/stiff ventricle
- ICD for primary prevention of sudden cardiac death when EF ≤35% despite optimal GDMT
