# Histopathology IHC Special Stains

## Special (Histochemical) Stains — Quick Reference
| Stain | Detects | Classic Use |
|---|---|---|
| **H&E** | General morphology (hematoxylin = basic, stains nuclei blue/purple; eosin = acidic, stains cytoplasm pink) | Routine histology |
| **PAS (Periodic Acid-Schiff)** | Glycogen, mucin, glycoproteins, basement membranes, fungal walls | Glycogen storage diseases, alpha-1 antitrypsin globules, fungal infections, basement membrane thickening (diabetic nephropathy) |
| **PAS with diastase (PASD)** | Distinguishes glycogen (diastase-sensitive, disappears) from mucin/glycoprotein (diastase-resistant, persists) | Alpha-1 antitrypsin deficiency (PAS+, diastase-resistant globules) |
| **Congo Red** | Amyloid | Apple-green birefringence under polarized light — amyloidosis |
| **Masson Trichrome** | Collagen (blue/green), muscle (red) | Fibrosis assessment (liver cirrhosis staging, cardiac fibrosis) |
| **Reticulin stain** | Reticular fibers (type III collagen) | Liver architecture, distinguishing carcinoma (destroyed reticulin) from hyperplasia |
| **Silver stains (Jones methenamine silver, GMS)** | Basement membranes (Jones); fungi (GMS - Grocott's methenamine silver) | Membranous nephropathy ("spikes"), fungal infections (Pneumocystis, Candida, Aspergillus) |
| **Prussian Blue (Perls stain)** | Iron (ferric/hemosiderin) | Hemochromatosis, hemosiderosis |
| **Von Kossa / Alizarin Red** | Calcium | Dystrophic/metastatic calcification |
| **Oil Red O / Sudan Black** | Fat/lipid (requires frozen section, dissolved by routine processing) | Fatty liver, lipid storage diseases |
| **Ziehl-Neelsen (acid-fast)** | Mycobacteria (acid-fast bacilli) | Tuberculosis, atypical mycobacteria |
| **Fite stain** | Acid-fast (modified, weakly acid-fast organisms) | Leprosy (M. leprae), Nocardia |
| **Giemsa** | Blood cells, parasites, H. pylori | Malaria, Leishmania, H. pylori gastritis |
| **Warthin-Starry** | Spirochetes, Bartonella | Syphilis, cat-scratch disease |
| **Mucicarmine** | Mucin (rose-pink) | Adenocarcinoma identification, Cryptococcus capsule |
| **Rhodanine stain** | Copper | Wilson disease |
| **Alcian Blue** | Acidic mucins | Mucin-producing tumors, differentiate from PAS+ neutral mucins |
| **Luxol Fast Blue** | Myelin | Demyelinating diseases (MS) |
| **Bielschowsky stain** | Neurofibrils | Neurodegenerative disease, neuroblastoma |
| **Trichrome (for amyloid) / Thioflavin T** | Amyloid (fluorescent alternative to Congo red) | Amyloidosis (fluorescence microscopy) |

## Immunohistochemistry (IHC) Markers — Organized by Category

### Epithelial Markers
| Marker | Use |
|---|---|
| **Cytokeratin (CK, pan-CK)** | Carcinomas (epithelial origin) |
| **CK7** | Lung, breast, ovarian, pancreatic, biliary adenocarcinoma (CK7+/CK20− pattern) |
| **CK20** | Colorectal, Merkel cell carcinoma, urothelial (CK7−/CK20+ pattern for colorectal) |
| **EMA (epithelial membrane antigen)** | Carcinomas, also meningioma, plasma cell tumors |

### Mesenchymal Markers
| Marker | Use |
|---|---|
| **Vimentin** | Sarcomas, mesenchymal tumors, also renal cell carcinoma |
| **Desmin** | Muscle tumors (leiomyoma/sarcoma, rhabdomyosarcoma) |
| **Myogenin/MyoD1** | Rhabdomyosarcoma (nuclear stain) |
| **SMA (smooth muscle actin)** | Smooth muscle tumors, myofibroblasts |
| **CD34** | Vascular tumors, GIST, dermatofibrosarcoma protuberans, solitary fibrous tumor |
| **CD31, Factor VIII (vWF)** | Endothelial/vascular tumors (angiosarcoma, Kaposi sarcoma) |
| **S-100** | Melanoma, neural tumors (schwannoma, neurofibroma), Langerhans cell histiocytosis, chondroid tumors |

### Neuroendocrine Markers
| Marker | Use |
|---|---|
| **Chromogranin, Synaptophysin** | Neuroendocrine tumors (carcinoid, small cell carcinoma, pheochromocytoma, medullary thyroid carcinoma) |
| **NSE (neuron-specific enolase)** | Neuroendocrine differentiation (less specific) |
| **CD56** | Neuroendocrine tumors, NK cell lymphoma |

### Lymphoid/Hematopoietic Markers
| Marker | Use |
|---|---|
| **CD45 (LCA - leukocyte common antigen)** | Confirms hematopoietic origin (lymphoma vs carcinoma vs sarcoma) |
| **CD20** | Mature B cells (most B-cell lymphomas) |
| **CD19, CD79a, PAX5** | B-cell lineage |
| **CD3** | T cells (pan T-cell marker) |
| **CD5** | T cells; aberrantly on CLL/SLL and mantle cell lymphoma (B-cell neoplasms) |
| **CD10** | Germinal center B cells (follicular lymphoma, Burkitt lymphoma), also ALL blasts (CALLA) |
| **CD15, CD30** | Classical Hodgkin lymphoma (Reed-Sternberg cells) |
| **CD23** | CLL (CD5+CD23+ helps distinguish from mantle cell CD5+CD23−) |
| **CD34** | Hematopoietic stem cells/blasts (also vascular tumors — context dependent) |
| **TdT** | Lymphoblasts (ALL/lymphoblastic lymphoma) |
| **CD117 (c-KIT)** | Mast cells, GIST, AML blasts, seminoma |
| **CD138** | Plasma cells (multiple myeloma) |
| **ALK** | Anaplastic large cell lymphoma (t(2;5)), ALK+ lung adenocarcinoma |
| **Cyclin D1** | Mantle cell lymphoma (t(11;14)) |
| **BCL2** | Follicular lymphoma (t(14;18)) — but also normal T cells (careful in interpretation) |

## Proliferation & Prognostic Markers
- **Ki-67**: proliferation index, used in grading neuroendocrine tumors, breast cancer prognostication, lymphoma grading (near 100% in Burkitt lymphoma)
- **p53**: overexpression (accumulation) suggests TP53 mutation in many carcinomas (endometrial serous carcinoma, high-grade tumors)
- **ER/PR/HER2**: breast cancer — determines hormonal therapy (tamoxifen) and targeted therapy (trastuzumab) eligibility; triple-negative breast cancer = ER−/PR−/HER2− (worse prognosis, no targeted therapy)

## High-Yield One-Liners
- Congo red + apple-green birefringence under polarized light = amyloid (gold standard stain)
- PAS + diastase-resistant globules = alpha-1 antitrypsin deficiency (periportal hepatocytes)
- Prussian blue (Perls stain) = iron/hemosiderin (hemochromatosis)
- CD45 (leukocyte common antigen) is the first marker to confirm a tumor is hematolymphoid in an undifferentiated malignancy workup
- CD15/CD30 = Reed-Sternberg cells of classical Hodgkin lymphoma
- TdT = marker of immature lymphoblasts, positive only in ALL/lymphoblastic lymphoma
- TTF-1 = lung adenocarcinoma and thyroid carcinoma marker — helps distinguish primary lung tumor from metastasis
- Desmin/Myogenin = rhabdomyosarcoma; S-100/HMB-45/Melan-A = melanoma
- CD117 (c-KIT) positive in GIST, mast cell tumors, seminoma, and a subset of AML
- Cyclin D1 (Bcl-1) IHC positivity supports mantle cell lymphoma diagnosis (t(11;14))
- Ki-67 proliferation index is used to grade neuroendocrine tumors and assess breast cancer aggressiveness
- ER/PR/HER2 status in breast cancer determines both prognosis and choice of targeted/hormonal therapy
