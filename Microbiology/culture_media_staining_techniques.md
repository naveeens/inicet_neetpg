# Culture Media Staining Techniques

## Overview
Selecting the right culture medium and stain is often the fastest route to a diagnosis in microbiology MCQs. This file consolidates media (selective, enriched, differential) and staining techniques (simple, differential, special) organized by organism/purpose.

## Culture Media by Purpose

### Enriched Media
| Medium | Composition/Basis | Used For |
|---|---|---|
| Blood agar | Nutrient agar + 5–10% sheep blood | General purpose; hemolysis patterns (alpha/beta/gamma) |
| Chocolate agar | Blood agar heated to lyse RBCs, releases nutrients (X and V factors) | *Haemophilus influenzae*, *Neisseria* spp. |
| Loeffler's serum slope | Coagulated serum | *Corynebacterium diphtheriae* — rapid growth, shows club-shaped morphology |

### Selective Media
| Medium | Selective Agent | Used For |
|---|---|---|
| MacConkey agar | Bile salts + crystal violet (inhibit gram-positives) | Gram-negative enteric bacilli; lactose fermentation differentiation (pink = fermenter) |
| Thayer-Martin (VCN) agar | Vancomycin, Colistin, Nystatin | *Neisseria gonorrhoeae* |
| TCBS agar | Thiosulfate-citrate-bile salts, alkaline pH | *Vibrio cholerae* (yellow, sucrose-fermenting colonies) |
| Löwenstein-Jensen medium | Malachite green | *Mycobacterium tuberculosis* |
| Bordet-Gengou medium | Potato-glycerol-blood + penicillin | *Bordetella pertussis* |
| Skirrow's medium | Vancomycin, polymyxin B, trimethoprim | *Campylobacter jejuni* (with microaerophilic incubation at 42°C) |
| Tellurite blood agar (Cystine-tellurite) | Potassium tellurite | *Corynebacterium diphtheriae* (black colonies) |
| Salmonella-Shigella (SS) agar | Bile salts, sodium citrate | *Salmonella*, *Shigella* |
| Sabouraud's dextrose agar (SDA) | Antibiotics (chloramphenicol) ± acidic pH | Fungi (general purpose) |
| Mannitol salt agar | 7.5–10% NaCl, mannitol, phenol red | *Staphylococcus aureus* (mannitol fermenter, turns medium yellow) |
| Hektoen enteric agar | Bile salts | *Salmonella*, *Shigella* — H2S producers form black colonies |

### Differential/Indicator Media
| Medium | Basis | Reads Out |
|---|---|---|
| MacConkey agar | Lactose + neutral red/pH indicator | Fermenters (pink) vs non-fermenters (colorless) |
| Triple Sugar Iron (TSI) agar | Glucose, lactose, sucrose + ferrous sulfate | Fermentation pattern + H2S production (blackening) |
| Blood agar | Hemolysins | Alpha (partial, greenish), beta (complete, clear), gamma (none) hemolysis |

### Transport Media
| Medium | Used For |
|---|---|
| Cary-Blair medium | Stool samples (*Vibrio*, enteric pathogens) |
| Sach's buffered glycerol saline | Stool specimens (non-cholera transport) |
| Amies/Stuart's medium | Swabs — general bacterial transport |
| Venkataraman-Ramakrishnan (VR) medium | *Vibrio cholerae* transport |

### Enrichment (Liquid) Media
| Medium | Used For |
|---|---|
| Selenite F broth / Tetrathionate broth | *Salmonella* enrichment from stool before plating |
| Robertson's cooked meat (RCM) medium | Anaerobes (esp. *Clostridium*) |
| Alkaline peptone water | *Vibrio cholerae* enrichment |

## Staining Techniques

### Simple/Differential Bacterial Stains
| Stain | Principle | Use |
|---|---|---|
| **Gram stain** | Crystal violet + iodine (mordant) retained by thick peptidoglycan (gram +ve, purple) vs washed out by decolorizer in thin-walled gram −ve (counterstained pink by safranin) | Primary bacterial identification |
| **Ziehl-Neelsen (ZN)** | Carbol fuchsin resists acid-alcohol decolorization due to mycolic acid | Acid-fast bacilli (*Mycobacterium*) |
| **Albert's stain** | Toluidine blue + malachite green | *Corynebacterium diphtheriae* — shows metachromatic granules |
| **Giemsa stain** | Romanowsky-type stain | Malaria parasites, blood films, *Leishmania*, *Borrelia*, chlamydial inclusions |
| **Negative staining (India ink)** | Background stained, capsule remains clear halo | *Cryptococcus neoformans* capsule |
| **Silver stain (Warthin-Starry / GMS)** | Silver impregnation | Spirochetes (*Treponema*), fungi (GMS = Gomori methenamine silver), *Legionella*, *H. pylori* |
| **Fluorescent antibody/Auramine-rhodamine** | Fluorochrome-tagged | Rapid TB screening, direct fluorescent antibody tests |
| **Fite-Faraco stain** | Modified acid-fast (milder decolorization) | *Mycobacterium leprae* in skin biopsy |
| **Lactophenol cotton blue** | Fungal wet mount stain | Morphology of molds (hyphae, spores/conidia) |
| **KOH mount** | Digests keratin/tissue, leaves fungal elements | Direct skin/nail/hair scraping for dermatophytes, Candida |
| **Wayson stain** | Simple stain | *Yersinia pestis* — "safety pin" appearance |
| **Dark-field microscopy** | No staining; light scatter | *Treponema pallidum* (too thin to see on Gram stain) |

### Motility & Special Preparations
| Technique | Use |
|---|---|
| Hanging-drop preparation | Motility (e.g., *Vibrio cholerae* darting motility, immobilized by specific antiserum) |
| Quellung reaction | Capsular swelling with specific antiserum — pneumococcus typing |
| Nigrosin/India ink | Negative staining for capsules |

## Biochemical Tests Quick Reference
| Test | Detects | Key Positive Organisms |
|---|---|---|
| Catalase | H2O2 → H2O + O2 (bubbles) | Staphylococcus (vs Streptococcus) |
| Coagulase | Plasma clotting | *S. aureus* |
| Oxidase | Cytochrome c oxidase | *Pseudomonas*, *Neisseria*, *Vibrio* (Enterobacteriaceae are oxidase negative) |
| Indole | Tryptophanase | *E. coli* (part of IMViC) |
| Urease | Urea hydrolysis → ammonia | *H. pylori*, *Proteus*, *Klebsiella* |
| Niacin | Niacin accumulation | *M. tuberculosis* (positive; distinguishes from most other mycobacteria) |
| Bile solubility | Autolysin activation by bile salts | *S. pneumoniae* |
| Optochin sensitivity | Ethylhydrocupreine sensitivity | *S. pneumoniae* |
| CAMP test | Synergistic hemolysis | *S. agalactiae* (Group B Strep) |

## High-Yield One-Liners
- Gram stain differentiates based on peptidoglycan thickness — retains crystal violet-iodine complex in thick-walled gram positives
- ZN stain relies on mycolic acid resisting acid-alcohol decolorization — hallmark of AFB
- India ink = negative stain showing the polysaccharide capsule of *Cryptococcus neoformans*
- Dark-field microscopy (not Gram/ZN) is used for *Treponema pallidum* — too thin to visualize by light microscopy after staining
- Albert's stain shows metachromatic granules in *C. diphtheriae* — club-shaped bacilli with polar bodies
- Löwenstein-Jensen (egg-based, malachite green) remains the classic solid TB culture medium despite BACTEC/MGIT being faster
- TCBS agar (yellow colonies) = selective/differential medium for *V. cholerae*
- Selenite F / tetrathionate broth = enrichment step before plating stool for *Salmonella*
- Cary-Blair medium = standard stool transport medium for suspected enteric pathogens
- Wayson stain "safety pin" morphology = classic clue for *Yersinia pestis*
- Quellung reaction = capsular swelling test, historically for pneumococcal serotyping
