# Amino Acid Metabolism Urea Cycle

## Overview
Amino acids undergo transamination/deamination to release nitrogen (as ammonia), which is toxic and must be converted to urea (urea cycle, liver) for safe excretion. Carbon skeletons feed into TCA cycle intermediates (glucogenic) or Acetyl-CoA/Acetoacetyl-CoA (ketogenic).

## Nitrogen Handling — Transamination and Deamination
| Process | Enzyme | Key Point |
|---|---|---|
| Transamination | Aminotransferases (ALT, AST) — require **Vitamin B6 (PLP)** as cofactor | Transfers amino group to α-ketoglutarate forming glutamate; ALT/AST used clinically as liver markers |
| Oxidative deamination | Glutamate dehydrogenase (GDH) | Glutamate → α-KG + NH3; only enzyme producing free ammonia in significant amounts; uses NAD+/NADP+; activated by ADP, inhibited by GTP/ATP |
| Ammonia transport | Alanine (from muscle, via alanine cycle to liver) and Glutamine (from most tissues, via glutamine synthetase, to liver/kidney) | Safe, non-toxic transport forms of nitrogen in blood |

## Urea Cycle — Steps (Liver Only, Mitochondria + Cytosol)
| Step | Enzyme | Location | Notes |
|---|---|---|---|
| NH3 + CO2 + 2ATP → Carbamoyl phosphate | **Carbamoyl phosphate synthetase I (CPS-I)** — rate-limiting enzyme | Mitochondria | Requires **N-acetylglutamate** as obligate allosteric activator |
| Carbamoyl phosphate + Ornithine → Citrulline | Ornithine transcarbamylase (OTC) | Mitochondria | Citrulline exported to cytosol |
| Citrulline + Aspartate → Argininosuccinate | Argininosuccinate synthetase | Cytosol | Uses ATP; incorporates 2nd nitrogen (from aspartate) |
| Argininosuccinate → Arginine + Fumarate | Argininosuccinate lyase | Cytosol | Fumarate re-enters TCA cycle (links urea cycle to TCA cycle) |
| Arginine → Ornithine + Urea | Arginase | Cytosol | Ornithine recycled back into mitochondria to continue cycle |

- Net: 2 NH3 (one as free ammonia/carbamoyl phosphate, one via aspartate) + CO2 + 3 ATP → 1 Urea + Fumarate
- N-acetylglutamate synthase (activated by arginine) makes the essential activator for CPS-I — key regulatory control point
- Urea cycle disorders → hyperammonemia; **OTC deficiency** = most common urea cycle disorder (X-linked)

## Amino Acid Classification (Glucogenic vs Ketogenic)
| Category | Examples |
|---|---|
| Purely ketogenic | Leucine, Lysine |
| Glucogenic and ketogenic | Isoleucine, Phenylalanine, Tyrosine, Tryptophan, Threonine |
| Purely glucogenic | Remaining amino acids (e.g., alanine, glutamate, aspartate, glycine, serine, valine, methionine, histidine, arginine, proline) |
| Essential amino acids | Mnemonic: "**PVT TIM HALL**" — Phenylalanine, Valine, Tryptophan, Threonine, Isoleucine, Methionine, Histidine, Arginine (semi-essential, infants/growth), Leucine, Lysine |

## Key Specialized Amino Acid Pathways
| Pathway | Key Enzyme | Clinical Relevance |
|---|---|---|
| Phenylalanine → Tyrosine | Phenylalanine hydroxylase (requires BH4/tetrahydrobiopterin) | Deficient in **Phenylketonuria (PKU)** |
| Tyrosine → Fumarate + Acetoacetate | Homogentisate oxidase | Deficient in **Alkaptonuria** (homogentisic acid accumulates) |
| Tyrosine → Melanin | Tyrosinase | Deficient in **Albinism** |
| Tyrosine → Catecholamines | Tyrosine hydroxylase (rate-limiting for catecholamine synthesis) | Dopamine → Norepinephrine → Epinephrine |
| Tryptophan → Niacin/Serotonin | Kynureninase pathway (needs B6) | Hartnup disease (impaired neutral amino acid transport incl. tryptophan) → pellagra-like features |
| Branched-chain AA (Leu, Ile, Val) catabolism | Branched-chain α-ketoacid dehydrogenase (needs same cofactors as PDH) | Deficient in **Maple Syrup Urine Disease** — sweet-smelling urine, neurologic damage |
| Methionine/Homocysteine | Cystathionine β-synthase (needs B6); Homocysteine → Methionine needs B12 + folate | Homocystinuria — CBS deficiency; marfanoid habitus, lens dislocation (downward), thromboembolism |
| Glycine cleavage | Glycine cleavage system | Nonketotic hyperglycinemia |
| Collagen synthesis | Prolyl/Lysyl hydroxylase (requires Vitamin C) | Deficient in **Scurvy** |

## Clinically Relevant Enzyme Deficiencies (Amino Acid Disorders)
| Enzyme Deficient | Disease | Key Feature |
|---|---|---|
| Phenylalanine hydroxylase | PKU | Intellectual disability, musty odor, hypopigmentation; managed with low-Phe diet, avoid aspartame |
| Homogentisate oxidase | Alkaptonuria | Dark urine on standing, ochronosis (bluish-black pigmentation of cartilage), arthritis — benign otherwise |
| Branched-chain ketoacid dehydrogenase | Maple syrup urine disease | Sweet/maple syrup odor of urine, poor feeding, lethargy |
| Cystathionine β-synthase | Homocystinuria | Marfanoid habitus, downward lens dislocation (vs upward in Marfan), thrombosis, intellectual disability |
| OTC | OTC deficiency (X-linked) | Most common urea cycle disorder; hyperammonemia, ↑orotic acid (excess carbamoyl phosphate shunted to pyrimidine synthesis), NO hyperammonemia-associated acidosis (unlike organic acidemias) |
| Arginase | Argininemia | Milder hyperammonemia, spasticity |

## High-Yield One-Liners
- Rate-limiting enzyme of urea cycle: **CPS-I**; requires N-acetylglutamate as allosteric activator
- OTC deficiency = most common urea cycle disorder; X-linked; ↑orotic acid without acidosis (distinguishes from organic acidemias which cause metabolic acidosis)
- Ammonia is transported in blood as glutamine (most tissues) and alanine (muscle, via alanine cycle to liver)
- PKU: deficient phenylalanine hydroxylase (or BH4 cofactor); classic mousy/musty odor
- Alkaptonuria: benign, homogentisic acid accumulation, dark urine + ochronosis
- Homocystinuria (CBS deficiency): downward lens dislocation vs Marfan's upward dislocation — classic exam differentiator
- Maple syrup urine disease: branched-chain ketoacid dehydrogenase deficiency, shares cofactors with PDH/α-KGDH
- Vitamin B6 (PLP) is the universal cofactor for transamination reactions
- Fumarate produced in the urea cycle links directly to the TCA cycle
